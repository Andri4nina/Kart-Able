# Internationalisation (i18n) et LanguageSelector

- **Type** : système + composant UI
- **Fichiers** : `src/locales/*.json`, `src/i18n/locales.js`, `src/i18n/translate.js`, `src/i18n/useTranslation.js`, `src/stores/localeStore.js`, `src/components/menu/LanguageSelector.jsx`, `scripts/check-locales.mjs`
- **Phase** : 1B (menu)

## Rôle

Tous les textes de l'interface passent par `t()`. Changement de langue instantané, sans rechargement, mémorisé entre les sessions. Aucune dépendance externe.

## Fonctionnement

1. `import.meta.glob('../locales/*.json', { eager: true })` découvre **automatiquement** chaque fichier de langue. Le nom affiché vient de `_meta.name`, l'ordre de `_meta.order`.
2. `localeStore` garde la langue active (persist `smkw-locale`). Au premier lancement : première langue du navigateur disponible, sinon `fr`. Une langue sauvegardée puis supprimée retombe sur la détection.
3. `useTranslation()` renvoie `{ t, locale, setLocale }`. Seuls les composants qui traduisent se re-rendent au changement de langue.
4. `translate(locale, key, params)` :
   - clé pointée : `t('mainMenu.play')`
   - variables : `t('players.player', { number: 2 })` avec `"Joueur {{number}}"`
   - pluriels : `t('players.upTo', { count: 8 })` avec `{ "one": ..., "other": ... }` (Intl.PluralRules)
   - ordinaux : `t('hud.ordinal', { ordinal: 1 })` avec `{ "one": "er", "other": "e" }`
   - repli sur `fr.json` si la clé manque (avertissement console en dev)
5. `App.jsx` met à jour `<html lang>` à chaque changement.

## Ajouter une langue

1. Copier `src/locales/fr.json` en `src/locales/<code>.json` (code ISO 639-1, ex. `es`).
2. Traduire les valeurs, renseigner `_meta.name` (nom natif) et `_meta.order`.
3. `npm run check:i18n` : clés manquantes, clés en trop et variables `{{x}}` différentes sont signalées.

Aucune autre modification : la langue apparaît dans les deux sélecteurs.

## LanguageSelector

| Variante | Où | Comportement |
| --- | --- | --- |
| `compact` | Menu principal, en haut à droite | Bouton (icône Languages + code) ; panneau Motion ; clic extérieur ou `Échap` ferme sans déclencher le retour global ; flèches pour naviguer |
| `list` (`LanguageList`) | Paramètres > Langue | Liste des langues, nom natif avec attribut `lang`, langue active cochée |

Sélecteurs de test : `#language-btn`, `#language-fr-btn`, `#language-en-btn`, `#language-mg-btn`.

## Évolutions prévues

Chargement paresseux des langues (`eager: false`) si leur nombre grossit ; formatage des nombres et durées via `Intl.NumberFormat` / `Intl.DateTimeFormat`. Les traductions malgaches peuvent être relues et ajustées directement dans `mg.json`.
